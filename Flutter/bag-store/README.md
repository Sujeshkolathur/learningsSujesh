# Saling — static bag store

A simple static marketing site for selling bags. No build step required.

## Open locally

Double-click `index.html`, or run a local server:

```powershell
cd c:\learning\Flutter\bag-store
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Files

- `index.html` — page structure and content
- `styles.css` — layout and visual design
- `script.js` — mobile menu and “Add to bag” toast
