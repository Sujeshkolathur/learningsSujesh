# Sujesh K R — Developer Portfolio

Static portfolio site built from resume content.

## Preview locally

```powershell
cd c:\learning\Flutter\sujesh-portfolio
python -m http.server 8080
```

Open `http://localhost:8080` or double-click `index.html`.

## Host for free

- **Netlify:** drag this folder to [app.netlify.com](https://app.netlify.com)
- **GitHub Pages:** push to a repo and enable Pages on `main`
- **Vercel:** import the folder at [vercel.com](https://vercel.com)

## Files

- `index.html` — content and structure
- `styles.css` — dark developer theme
- `script.js` — mobile nav and section highlighting
